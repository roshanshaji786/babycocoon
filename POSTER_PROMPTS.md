## 🛠️ How to use the text-baked prompts

1. Copy a TEXT-BAKED prompt → paste in ChatGPT → it returns a poster **with all text included**.
2. Regenerate 3–4× until the text is clean (AI sometimes misses a letter — pick the best).
3. Post directly — **no Canva needed.**
4. If text comes out garbled, re-run with: `all text must be spelled correctly, short text only` — and/or shorten the lines.

> ⚠️ **Honest designer note:** AI-rendered text is never 100% reliable. For a *client-facing* hero piece, the Canva overlay route (original prompts below) is still the safest. For Instagram stories/quick posts, these text-baked prompts are perfect. Do a test run of both and see which you prefer.

## ⚡ The 5 rules of a high-converting poster (designer's checklist)

1. **One focal point** — a sleeping baby (emotion) OR your design on devices (proof). Never both competing.
2. **Your brand palette in the image** — prompt the exact hex colors so the poster matches babycocoon.co.in.
3. **Text-free image first** — AI models garble text. Generate the artwork WITHOUT words, then add text in **Canva / Photoshop** (15 min). This is the professional workflow.
4. **Negative space at the top** — always prompt "generous empty space at top for headline" so your text has a home.
5. **One CTA** — one action, big. Never two.

## 🛠️ How to use (exact workflow)

1. **Copy a prompt** → paste in ChatGPT (with an image model enabled) → it returns a **text-free artwork**.
2. **Regenerate** 3–4 times, pick the best.
3. **Open Canva** (free) → upload the image → add your headline + CTA + **your name/handle** with a clean font (Fraunces/Nunito to match, or bold sans).
